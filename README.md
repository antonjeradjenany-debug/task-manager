 # Task Management REST API

A production-ready Task Management RESTful API built with **Node.js**, **Express**, **TypeScript**, **Prisma ORM**, and **PostgreSQL**. Includes full CRUD operations, dynamic query filtering, strict input validation, and centralized global error handling.

## 🚀 Tech Stack

- **Runtime:** Node.js
- **Framework:** Express.js
- **Language:** TypeScript
- **ORM:** Prisma
- **Database:** PostgreSQL

## 📋 Prerequisites

Make sure you have the following installed on your machine:
- [Node.js](https://nodejs.org/) (v18 or higher)
- [PostgreSQL](https://www.postgresql.org/)
- npm or yarn
